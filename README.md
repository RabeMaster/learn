# learn

공부와 블로그를 위한 저장소입니다.

## 구성

- 주제별 `NNN_주제/` 폴더 (예: `001_java/`, `002_gc/`)
- 글은 `NNN_제목.md`, 이미지는 폴더별 `images/`

## 셋업

클론 후 한 번 실행해 커밋 훅을 켭니다.

```sh
git config core.hooksPath .githooks
```
