# learn

공부와 블로그를 위한 저장소입니다.

## 구성

- 주제별 `NNN_주제/` 폴더
- 글은 `NNN_제목.md`, 이미지는 폴더별 `images/`
- 각 폴더의 `000_목차.md`는 그 폴더의 목차이자 진행 상태표

## 주제

| 폴더                                    | 내용                |
| ------------------------------------- | ----------------- |
| [001_db](001_db/000_목차.md)         | 트랜잭션, 동시성, 인덱스    |
| [002_api](002_api/000_목차.md)       | 멱등성, 재시도, HTTP 설계 |
| [003_spring](003_spring/000_목차.md) | 트랜잭션 처리, 커넥션 풀    |

## 셋업

클론 후 한 번 실행해 커밋 훅을 켭니다.

```sh
git config core.hooksPath .githooks
```
